# 🌤️ Weather App

A modern and responsive **Weather Web App** built using **HTML, CSS, and JavaScript**.  
This application fetches real-time weather data from the OpenWeather API and displays important weather information based on the city entered by the user.

---

## 🚀 Features

* 🔍 **City Search** – Search weather using any city name
* 🌡️ **Live Temperature** – Displays current temperature in Celsius
* 🌤️ **Weather Condition** – Shows current weather status
* 💨 **Wind Speed** – Displays wind speed information
* 🥵 **Feels Like Temperature** – Shows perceived temperature
* 💧 **Humidity Information** – Displays humidity percentage
* 📱 **Responsive Design** – Works on mobile and desktop
* ⚡ **Real-Time API Data** – Fetches live weather updates
* 🎨 **Modern UI Design** – Glassmorphism styled interface

## 🎯 How It Works

1. User enters a **city name**
2. Clicks the **Search button**
3. App sends a request to the OpenWeather API
4. API returns weather data in JSON format
5. Application extracts information like:

   * Temperature
   * Weather condition
   * Wind speed
   * Feels like temperature
   * Humidity
6. Weather information is dynamically displayed on the screen
